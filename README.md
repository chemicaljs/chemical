# Chemical

Easily create your own web proxy with no experience required. V3 uses Scramjet and is Svelte 5 only.

## Docs

Full documentation is at https://chemicaljs.github.io.

## Dev Server

The repo includes a local dev environment for testing Chemical and building new features.

```bash
pnpm install

# Start Vite dev server (http://localhost:5173)
pnpm dev

# Build the dev app for production
pnpm build

# Serve the production build through Chemical's own Express server
pnpm start
```
